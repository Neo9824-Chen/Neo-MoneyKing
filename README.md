# Neo-MoneyKing · 迎财神桌面摆件

**创作者：Neo · 联系：Neo9824**

一个用 Electron 做的「迎财神」桌面摆件小工具：上班倒计时 + 自动敲木鱼攒财富；点右上角「缩小」变成可拖动、无边框、背景透明的财神，悬停出现「放大」，原地单击摆件恢复主窗口。设置里有上下班时间、音量、背景音效（自动敲击）、缩小后背景音效（摆件），均即时生效；手动敲击音效常开。

> 完整桌面摆件版需要本机有 **Node.js LTS**（用来跑 Electron）。没有 Node.js 也行：直接双击 `index.html` 用浏览器打开也能跑，但那种「缩小」只是网页内小窗，不是无边框透明桌面摆件。

---

## 一、前置条件

- 安装 **Node.js LTS**：https://nodejs.org
- 首次启动会自动下载 **Electron（约 100MB）**，需要联网；国内默认走 npmmirror 镜像，失败会自动回退官方源。

---

## 二、方式 A：通过 WorkBuddy 部署（推荐 WorkBuddy 用户）

1. 把本仓库 clone / 下载，放到 WorkBuddy 的技能目录：
   - Windows：`%USERPROFILE%\.workbuddy\skills\neo-moneyking\`
   - macOS / Linux：`~/.workbuddy/skills/neo-moneyking/`
   （解压或 clone 后，**这个文件夹里应该直接能看到 `SKILL.md` 和 `index.html` 在同一层**，中间不要再套子文件夹。）
2. 重启 / 刷新 WorkBuddy。
3. 在对话里说一句：
   > 部署迎财神
   （或「安装 Neo-MoneyKing」「把财神放到我电脑上」）
4. WorkBuddy 会自动运行 `deploy.py`，把完整版装到默认的 `~/Documents/Neo-MoneyKing`，并安装 Electron 依赖。想让它顺手打开就再补一句「启动迎财神」。
5. 以后每次用：Windows 双击 `start.cmd`，macOS / Linux 在终端执行 `./start.sh`。

---

## 三、方式 B：通过豆包 PC 客户端部署（推荐豆包用户）

豆包 PC 客户端（桌面版）支持本地「技能」和「工作任务」模式，可以在你**自己的电脑**上执行脚本。

1. 先把本仓库下载到本地（clone 或下载 ZIP 解压皆可）。
2. 打开豆包 PC 客户端 → 新建一个「工作任务」→ 打开「本地电脑」运行权限（关键：一定要选**本地电脑**，别选云电脑，云电脑里装的东西一会儿就没了）。
3. 安装这个技能（二选一）：
   - **从 GitHub 安装**：在任务里直接发一句话，例如
     > 请安装这个 GitHub 仓库里的 Neo-MoneyKing 技能：<你的仓库地址>，安装为本地技能
     （豆包会自动识别仓库里的 `SKILL.md` 并安装。）
   - **手动上传**：左侧「插件 · 技能 · 伙伴」→「技能」页 → 右上角「+ 添加」→「上传技能」，把本仓库里的 `SKILL.md`（或整个文件夹 / ZIP）拖进去即可。
4. 安装完成后，在任务里说：
   > 部署迎财神
   豆包会自动运行 `deploy.py`，把桌面摆件装到 `~/Documents/Neo-MoneyKing` 并装好 Electron。
5. 装好后按提示双击 `start.cmd`（Windows）/ 运行 `./start.sh`（macOS / Linux）启动；也可以让豆包「启动迎财神」。

> 提示：豆包里如果看到「运行权限」「本地执行」这类开关，记得都打开，否则脚本跑不起来。第三方技能涉及读写本地文件时会弹权限请求，按需允许即可。

## 四、方式 C：纯手动（任何人都行）

1. 安装 Node.js LTS（见上）。
2. 把本仓库整个文件夹拷到电脑任意位置。
3. Windows 双击 `start.cmd`；macOS / Linux 在终端 `cd` 进目录后执行 `./start.sh`。
4. 首次会联网装 Electron，之后完全离线运行。

## 五、怎么用

- 主窗口：上班倒计时 + 自动敲木鱼攒财富。
- 点右上角「缩小」→ 变成可拖动的透明财神摆件；**悬停出现「放大」**，或**原地单击摆件**恢复主窗口；按住拖动可移动位置。
- 「设置」：上下班时间、音量、背景音效（自动敲击）、缩小后背景音效（摆件），四项即时生效；手动敲击音效常开；「取消」撤销本次未确定改动。

## 六、替换贴纸 / 音效

素材和 `index.html` 在同一层（平铺，无子目录），页面用相对路径引用：

| 文件 | 作用 |
| --- | --- |
| `caishen.png` | 顶部 logo |
| `monk.png` | 财神主体 |
| `mallet.png` | 木槌 |
| `muyu_knock.mp3` | 木鱼单次敲击音效 |

保持文件名不变、直接覆盖同名文件，重启应用或刷新即可生效。整个文件夹可拷到任何电脑、任何盘符、任何用户目录；不要把引用改成盘符绝对路径或网络链接，否则换台电脑找不到素材。素材文件丢了也没关系：页面内置了一份默认素材会自动顶上（只是你替换的不再生效）。

## 七、常见问题

- **没有声音**：浏览器 / Electron 要求先有一次用户交互才允许播放音频，点一下财神即可。
- **Electron 装不上**：检查 Node.js/npm 是否装好（`node -v`、`npm -v`）；网络问题可手动进安装目录执行 `npm install`；国内镜像失败会自动回退官方源。
- **窗口透明/摆件不透明**：透明无边框是真·桌面摆件版才有的特性（完整版）；纯网页版「缩小」只是页内小窗，不是透明摆件。
- **财富数清零**：财富与设置存在本机（localStorage / Electron 用户数据），清除这些数据会归零；重装应用本身不会清零。
- **数据都在本地**：图片与音效都在本地，完全离线可用，不依赖任何图床、CDN 或账号。
